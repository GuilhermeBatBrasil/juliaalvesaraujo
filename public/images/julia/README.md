# Imagens da Júlia

Os arquivos aqui são **placeholders** gerados por `scripts/generate-placeholders.mjs`.
Para publicar as fotos reais, basta substituir cada arquivo mantendo o mesmo nome —
nenhum componente precisa ser alterado.

| Arquivo | Onde aparece | Proporção sugerida |
| --- | --- | --- |
| `hero.jpg` | Hero (foto circular) | 1:1 |
| `about.jpg` | Seção "Muito Prazer, Sou a Júlia" | 4:5 |
| `contact-1.jpg` | Contato — imagem grande da colagem | 3:4.2 |
| `contact-2.jpg` | Contato — colagem (superior) | 4:3 |
| `contact-3.jpg` | Contato — colagem (inferior) | 4:3 |
| `instagram-1..8.jpg` | Grade do Instagram | 1:1 |

O enquadramento (`object-position`) de cada imagem está definido no CSS Module da
respectiva seção e pode ser ajustado após a troca das fotos.
